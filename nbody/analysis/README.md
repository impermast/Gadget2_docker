# Analysis archive and output map

`nbody/scripts/analysis/` is the canonical analysis implementation. Generated runner output is rooted here and placed by `AnalysisPaths`; do not write to an ad-hoc output directory. The current plot catalog is [`REGISTRY.md`](REGISTRY.md), generated by `registry_docs.py`.

| Directory | Purpose |
|---|---|
| `ic/<ic>/` | Initial-condition gates and profiles |
| `prerun/<run>/` | Early/partial-run metrics and plots |
| `core/<run>/` | Single-run analysis |
| `campaigns/<campaign>/` | Group/run comparisons |
| `previous_runs/` | Read-only historical artifacts migrated from `nbody/analyse/` |
| `presentations/` | Curated presentation sources/assets; no runner |

Outputs from `nbody/analyse/` were migrated without editing their contents (move trace: git rename history). Corecusp outputs under `nbody/runs/` were deliberately not migrated because run status remains an independent scientific decision. Tracked text reports and metadata are preserved; generated images/animations stay ignored by `.gitignore`.
